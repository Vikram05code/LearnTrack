#  JVM Basics

##  What is JDK?

JDK (Java Development Kit) is a complete package used to develop Java applications. It includes JRE and development tools like compiler (javac).

---

##  What is JRE?

JRE (Java Runtime Environment) provides libraries and JVM required to run Java programs.

---

##  What is JVM?

JVM (Java Virtual Machine) is responsible for executing Java bytecode. It makes Java platform-independent.

---

##  What is Bytecode?

When Java code is compiled, it is converted into bytecode (.class file). This bytecode is executed by JVM.

---

##  Write Once, Run Anywhere

Java programs can run on any system with a JVM, without modification. This is achieved because bytecode is platform-independent.
